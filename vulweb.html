Training Console

Seven bugs are live on this page. Click a ticket once you've found the issue to reveal the kitchen notes and mark it done.

#001
Client-Side Price Trust
unsolved
The price shown for every dish lives in a data-price attribute the browser fully controls. Edit it in devtools before adding to cart — the total follows it. Category: Security Misconfiguration / trusting client input.
#002
Negative Quantity Logic Flaw
unsolved
The quantity field in your cart accepts negative numbers, which subtract from the total instead of being rejected. Category: broken business logic / missing input validation.
#003
Hardcoded Secret in Client Code
unsolved
View the page source — a staff-only promo code is sitting in plain JavaScript, fully usable by anyone who reads it. Category: security misconfiguration / secrets shipped to the client.
#004
Order Tracking IDOR
unsolved
Tracking doesn't check who you are — only the order number. Change it and you're reading someone else's name, phone, and address. Category: IDOR / Broken Object-Level Authorization.
#005
Unprotected Staff Portal
unsolved
The footer link to the staff portal opens straight to full order and payment data — logging in changes nothing about whether you can reach it. Category: Broken Access Control.
#006
Unsanitized Review Rendering
unsolved
Reviews are inserted straight into the page's HTML. Try posting a review containing an image tag with a broken source and an onerror handler. Category: Cross-Site Scripting (XSS).
#007
Filter Bypass on Search
unsolved
One "86'd" item is filtered out of normal results. A classic tautology-style search string flips the filter's logic and surfaces it anyway. Category: injection-style filter bypass (conceptual, not real SQL here).
